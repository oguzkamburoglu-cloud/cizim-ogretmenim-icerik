# Çizim Öğretmenim – ders sesleri

Çizim Öğretmenim uygulamasının ders seslendirmeleri. Uygulama, çocuğun diline ait sesleri buradan indirir ve cihazda saklar.

- `icerik.json`: dosya listesi
- `dersler/<ders>/ses/<dil>/`: ders sesleri
- `sesler/sandik/<dil>/`: ünite sandığı sesleri

Dosyalar `tool/paketle.py` ile üretilir; elle düzenlemeyin.
